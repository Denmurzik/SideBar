# Правила для агентов команды SideBar (фаза исследования)

Проект: `C:\D\den4ik\SideBar`. Сначала прочитай `docs/PLAN.md` (решения, спайки S1–S10) и `HANDOFF.md`
(реверс-инжиниринг Quick Share). Работаешь только в своих путях, всё остальное — только чтение.

## Общий рабочий каталог — без конфликтов
- Не делай `git commit`/`git add`/`git stash`/`git checkout`/`git reset` — коммитит только тимлид. Read-only git (`status`, `diff`, `log`) можно.
- Не трогай чужие пути. Нашёл проблему вне своих путей — сообщи тимлиду.

## Тяжёлые операции — строго по одной на машину
Машина: 15.5 ГБ RAM, прошлые параллельные прогоны её вешали. Перед любой `dotnet build/publish/test`, сборкой NativeAOT,
запуском Ghidra и т.п.:
1. Проверь свободную RAM: `powershell -NoProfile -Command "(Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory/1MB"` (печатает ГБ). Меньше 3 ГБ — подожди и не запускай.
2. Возьми лок атомарно: `mkdir C:/D/den4ik/SideBar/.buildlock` (если каталог уже есть — кто-то собирает; подожди 30–60 с через Monitor/повтор, не трогай чужой лок). Положи внутрь файл со своим именем.
3. После операции — обязательно `rm -rf C:/D/den4ik/SideBar/.buildlock`.
Сборки делай с `-m:1` / `-p:BuildInParallel=false` где уместно. Не держи запущенными собственные процессы после проверки.

## Секреты — никогда не выводить
`%LOCALAPPDATA%\Google\Nearby\Sharing\` содержит приватные ключи (`preferences.json`, leveldb), cookies и токены в логах.
- Никогда не печатай, не логируй, не сохраняй в репозиторий значения ключей, секретов, токенов, cookies, идентификаторов аккаунта, email.
- Можно: имена полей, типы, длины в байтах, количество записей, номера protobuf-полей, первые 2 байта hex для распознавания формата.
- Файлы оттуда открывай только на чтение. Нужно открыть leveldb — скопируй каталог во временную папку ВНЕ репозитория (`%TEMP%\sidebar-certs-<rand>`), работай с копией, удали после.
- Ничего не меняй в `C:\Program Files\Google\NearbyShare` и `%LOCALAPPDATA%\Google`.

## Внешний мир
- Можно: скачивать NuGet/pip-пакеты, клонировать референсные репозитории в `C:\D\den4ik\refs\` (вне репозитория), читать веб.
- Нельзя: публиковать что-либо, пушить, создавать issues, менять системные настройки, отключать автозапуск чужих приложений.
- Проверки с реальным телефоном (Pixel 9) делает пользователь. Подготовь готовую команду и точный сценарий, отправь тимлиду — он соберёт запросы пачкой.

## Стиль
- Документы (`docs/research/*.md`) — по-русски, кратко, факты отдельно от гипотез, с указанием «проверено / не проверено».
- Код — C# (.NET 10, `net10.0-windows10.0.26100.0` где нужен WinRT), идентификаторы и комментарии на английском, комментариев мало.
- Портировать код из Apache-2.0 (`google/nearby`) можно с атрибуцией в шапке файла. Из других репозиториев — только после того, как `docs/research/licenses.md` подтвердит лицензию.

## Отчёт

Застрял или нужно решение — сразу пиши тимлиду, не угадывай.
