# M7 — Релиз: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Первый релиз SideBar: интерфейс на русском и английском по языку системы, установщик Inno Setup (с правилом брандмауэра для приёма Quick Share), ежедневная проверка новой версии со ссылкой, сборка установщика и GitHub Release в CI по тегу.

**Architecture:** Таблицы строк — в Core (`SideBar.Core.Localization`), чтобы их можно было проверить тестами; `SideBar.App.Strings` выбирает таблицу один раз при старте по `CultureInfo.CurrentUICulture`. Проверка версии — чистая политика и сравнение версий в Core, HTTP-запрос — в App. Установщик — `installer/SideBar.iss`, собирается в CI из NativeAOT-публикации.

**Tech Stack:** C# / .NET 10, WinUI 3 unpackaged, NativeAOT, xunit.v3, Inno Setup 6, GitHub Actions.

**Spec:** `docs/PLAN.md` (§2 «Язык UI», «Распространение», §3 CI, §6 M7), ledgers M1–M5.

## Global Constraints

- Всё из M1–M5 (AOT-safe, без активации окон, логи — белый список, коммиты без трейлеров + push, сборки по одной под `.buildlock`, тесты — запуском exe).
- Язык: русский, если `CultureInfo.CurrentUICulture.TwoLetterISOLanguageName == "ru"`, иначе английский. Выбор один раз при старте. Никаких строк UI вне таблиц (трей, плитки, окна-запросы, уведомления, подсказки).
- Версия — одна, в `Directory.Build.props` (`<Version>0.1.0</Version>`); тег релиза `v<версия>`; `SideBar.exe` сообщает её через `AssemblyInformationalVersion` (без хэша коммита в строке для сравнения).
- Проверка версии: не чаще раза в 24 ч и не раньше 2 мин после старта; `GET https://api.github.com/repos/Denmurzik/SideBar/releases/latest` с `User-Agent: SideBar/<версия>`, таймаут 10 с; без токенов; любой неуспех (сеть, 404 у приватного репозитория, разбор) — тихо, только запись типа ошибки в лог; новая версия → пункт трея «Доступна версия X.Y.Z» (открывает `html_url` релиза в браузере, только `https://github.com/`) — без уведомлений. Время последней проверки — в `AppState` (M5).
- Установщик: Inno Setup 6, `PrivilegesRequired=admin`, `{autopf}\SideBar`, языки Russian + English, `CloseApplications=yes`; правило брандмауэра `netsh advfirewall firewall add rule name="SideBar Quick Share" dir=in action=allow program="{app}\SideBar.exe" protocol=TCP profile=private` при установке и удаление этого правила при деинсталляции; значение `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SideBar` удаляется при деинсталляции; запуск после установки — `runasoriginaluser`. На машине пользователя установщик не запускается (только CI).
- CI: сборка установщика — на каждом push (артефакт), GitHub Release — только на теге `v*` (`permissions: contents: write` только у этого job), к релизу прикладывается `SideBar-<версия>-setup.exe`.

## Review Focus

1. Английская Windows → ни одной русской строки в трее, плитках, окне-запросе приёма. Тест — Task 1 (таблица EN без кириллицы, все ключи заполнены).
2. RU- и EN-строка с параметрами (`{0}` и т. п.) различаются числом/номерами параметров → `string.Format` падает только на одном языке. Тест — Task 1.
3. Репозиторий приватный → API отвечает 404 → ни ошибки, ни пункта в трее, следующая попытка через 24 ч. Тест — Task 2 (политика + разбор ответа).
4. Тег `v0.1.0`, а сборка сообщает `0.1.0+abc123` → сравнение версий не считает это «новой версией». Тест — Task 2.
5. Повторная установка поверх работающего SideBar → приложение закрыто, обновлено и запущено снова, второе правило брандмауэра не создаётся. Проверка — Task 3 (скрипт удаляет правило перед добавлением; Restart Manager).
