# Окно настроек: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Окно «Настройки» (трей → «Настройки…») в стиле «Параметров» Windows 11, где пользователь меняет поведение SideBar без правки реестра и переменных окружения.

**Architecture:** Модель настроек и её атомарное хранилище — в Core (`SideBar.Core.Settings`, `%LocalAppData%\SideBar\settings.json`, source-gen JSON, как `ShelfStore`), с событием `Changed`; сервисы подписываются на модель. Окно — обычное активируемое WinUI-окно (Mica, `NavigationView` слева, карточки справа), одно на процесс; закрытие окна освобождает его (память в фоне — как в M1).

**Tech Stack:** C# / .NET 10, WinUI 3 unpackaged, NativeAOT, xunit.v3.

**Spec:** запрос пользователя 2026-10-23 (разделы «Основное», «Quick Share», «Панель», «Временный буфер» + путь к официальному Quick Share; вид — как Параметры Windows 11); `docs/PLAN.md`; ledgers M1–M4.

## Global Constraints

- Всё из M1–M5 (AOT-safe, без активации карточки/веера, логи — белый список, коммиты без трейлеров + push, сборки по одной под `.buildlock`, тесты — запуском exe, RAM ≥ 3 ГБ перед сборкой).
- Окно настроек — единственное окно SideBar, которое активируется (обычное окно с заголовком и кнопками, Mica, тёмная/светлая тема по системе, min 640×480 epx, открывается по центру основного монитора, повторный выбор пункта трея поднимает уже открытое окно).
- Без сторонних NuGet-пакетов UI (свои карточки-стили в духе Windows 11 Settings: заголовок, описание, элемент управления справа).
- Изменения применяются сразу (без кнопки «Сохранить»), кроме языка (подпись «Применится после перезапуска»).
- Настройки (значения по умолчанию в скобках):
  - **Основное:** «Запускать при входе в Windows» (как сейчас в трее); «Язык»: Авто / Русский / English (Авто); «Проверять обновления» (вкл) + версия, «Проверить сейчас», ссылка на релизы.
  - **Quick Share:** «Видимость»: Скрыто / Свои устройства / Все (10 мин) — та же модель, что в трее; «Имя этого ПК» (имя компьютера, 1–32 символа, санитизация как у имён устройств); «Папка для принятых файлов» («Загрузки», кнопка «Изменить…», «Сбросить»); «Сертификаты Quick Share»: статус (загружены · устройств N · действуют до … / недоступны: причина) + «Обновить сейчас» (M5); «Путь к официальному Quick Share» (`C:\Program Files\Google\NearbyShare\nearby_share.exe`, «Изменить…» — выбор .exe, «Сбросить»; путь проверяется на существование, иначе предупреждение в карточке).
  - **Панель:** «Задержка открытия у края»: 0 / 150 / 300 мс (150); «Подпрыгивать при входящих» (вкл); «Показывать в полноэкранных приложениях» (выкл; перетаскивание файла к краю работает всегда).
  - **Временный буфер:** «Автоматически убирать файлы из буфера через»: Никогда / 1 день / 7 дней (Никогда); «Очистить буфер» (с подтверждением в самой карточке: кнопка превращается в «Точно очистить?» на 5 с).
  - **О программе:** версия, лицензия GPLv3, ссылка на репозиторий.
- Значения из настроек заменяют переменные окружения только для своих полей; `SIDEBAR_*` DEBUG-переопределения остаются приоритетнее в DEBUG.
- `VisibilityMode`, сохранённый M4 в `HKCU\Software\SideBar`, переносится в `settings.json` при первом запуске (после переноса значение реестра удаляется).

## Review Focus

1. Повреждённый `settings.json` → все значения по умолчанию, файл в карантин (`settings.bad-<ts>.json`), приложение работает. Тест — Task 1.
2. Папка для принятых недоступна (удалена, сетевой диск) → приём пишет в «Загрузки», в карточке предупреждение. Тест — Task 3.
3. Имя ПК с управляющими символами / 200 символов → санитизация и обрезка, реклама не ломается. Тест — Task 1.
4. Окно открыто, параллельно меняется видимость из трея (или по таймеру «Все» → прежняя) → радиокнопки в окне обновляются. Тест — Task 2 (модель) + проверка в UI.
5. Путь к официальному Quick Share указывает на несуществующий файл → цикл M5 возвращает NotInstalled, без запуска чего-либо, предупреждение в карточке. Тест — Task 3.
