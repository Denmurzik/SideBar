# M1 — каркас SideBar: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Фоновое приложение SideBar: карточка из макета выезжает пружиной с правого края основного монитора по курсору, в трее — иконка с автозапуском и выходом, в скрытом состоянии процесс держит единицы МБ.

**Architecture:** Чистая логика (геометрия карточки, пружина, автомат состояний края, автозапуск) — в библиотеке `SideBar.Core` без WinUI, покрыта юнит-тестами. Приложение `SideBar.App` (WinUI 3, unpackaged, NativeAOT) — тонкий слой Win32/WinUI: окно-карточка (вариант B из S10: окно = карточка и двигается само), низкоуровневый хук мыши (S8), трей, обрезка памяти (S7). Код спайков `spikes/ui/S10Spring`, `spikes/ui/S8Edge` — источник проверенных приёмов, переносится, а не подключается.

**Tech Stack:** .NET SDK 10.0.402, C#, WinUI 3 (Microsoft.WindowsAppSDK split-пакеты 2.x, как в `spikes/ui/S10Spring/S10Spring.csproj`), NativeAOT, xunit.v3 (`xunit.v3.mtp-v2` 4.0.2), GitHub Actions `windows-latest`.

**Spec:** `docs/PLAN.md` (разделы 1, 2, «Дефолты», 3, 6/M1) + `docs/research/review-2026-10-22.md` (пункты этапа M1: #17, #22) + `docs/research/ui.md` (S7, S8, S10).

## Global Constraints

- Только Windows 11, только основной монитор, правый край. `TargetFramework` `net10.0-windows10.0.26100.0`, `TargetPlatformMinVersion` `10.0.22621.0`, `x64`, `win-x64`.
- App: `WindowsPackageType=None`, `WindowsAppSDKSelfContained=true`, `SelfContained=true`, `PublishAot=true`, `InvariantGlobalization=true`, `AllowUnsafeBlocks=true`, PerMonitorV2 в `app.manifest`. Публикация без IL/AOT-предупреждений.
- P/Invoke только AOT-совместимый: `[DllImport]`/`[LibraryImport]` + `delegate* unmanaged` + `[UnmanagedCallersOnly]` (как в спайках); без `Marshal.GetFunctionPointerForDelegate`, без рефлексии.
- Карточка: 216×469 epx, отступ от края 8 epx, peek — видно 10 epx, плитки 192×216 epx через отступы 12 epx (`RowDefinitions="*,12,*"`), скругление карточки — системное `DWMWCP_ROUND` (8 px), плитки — `CornerRadius 4`; верхняя плитка — сплошная обводка, нижняя — пунктир `StrokeDashArray="4 3"`; все линии — 1 физ. px (`1/scale` epx), пунктир с `Margin = 0.5/scale`. Цвет обводок: тёмная тема `#708C8C8C`, светлая `#50404040`. Фон — `DesktopAcrylicBackdrop` + тинт `#40202020`. DWM-граница выключена (`DWMWA_BORDER_COLOR = 0xFFFFFFFE`), non-client рамка убрана (`WM_NCCALCSIZE` → 0 через `SetWindowSubclass`). Не в Alt-Tab (`IsShownInSwitchers=false`, `WS_EX_TOOLWINDOW`), всегда сверху.
- Пружина выезда: аналитическая затухающая, ζ = 0.8, response 0.35 с, прерываемая с сохранением позиции и скорости; «успокоилась» при |x − цель| < 0.5 px и |v| < 5 px/с.
- Край: peek-зона — 1 см = `dpi / 2.54` px от правого края; по вертикали — карточка ± 1 см; «касание» — `x ≥ right − 1`; скрытие через 300 мс после ухода с карточки; пока зажата ЛКМ — Open не закрывается; из Hidden не выезжает при полноэкранном (`QUNS_RUNNING_D3D_FULL_SCREEN`=3, `QUNS_PRESENTATION_MODE`=4, или `QUNS_BUSY`=2 **и** окно переднего плана (не `Progman`/`WorkerW`/`Shell_TrayWnd`/`Windows.UI.Core.CoreWindow`) покрывает весь монитор), кроме случая зажатой ЛКМ.
- Скрыто: `AppWindow.Hide()` + `EmptyWorkingSet`, повтор обрезки каждые 45 с, пока скрыто.
- Автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `SideBar` = `"<полный путь к exe>"`. По умолчанию выключен (включается из трея).
- Строки UI — по-русски, собраны в одном классе `Strings` (EN — в M7).
- Коммиты — без `Co-Authored-By`; после каждого коммита `git push`.
- Тесты: собранный `tests/SideBar.Core.Tests/.../SideBar.Core.Tests.exe` запускается напрямую (`dotnet test` с xunit.v3 на .NET 10 даёт «Handshake failures» — см. `spikes/nearby`). Перед полным прогоном проверить свободную RAM (< 2 ГБ — частями). Сборки — по одной.

Смена конфигурации экранов во время работы (разрешение, масштаб, подключение монитора справа) — карточка пересчитывает геометрию по `WM_DISPLAYCHANGE`/`WM_DPICHANGED`/`WM_SETTINGCHANGE`, не «уезжает» и не остаётся на старых координатах. Тест: `CardLayout` для 125 % и для монитора со смещённым началом координат (Task 1); пересчёт по сообщению — Task 4.

3. Второй запуск (автозапуск + ручной) — второй процесс сразу выходит, первый жив. Тест — Task 5.
4. Exe перемещён/обновлён после включения автозапуска — при старте, если автозапуск включён, путь в `Run` переписывается на текущий. Тест — Task 5.
5. Монитор справа от основного (#17): край не «упирается», окно за краем видно на соседнем экране. Тест — Task 2 (in-place режим).
