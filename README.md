# SideBar

Выезжающая с правого края экрана панель для Windows 11 (WinUI 3, NativeAOT):

- **полка** — временное хранилище для drag-and-drop между приложениями: до 10 элементов, есть корзина;
- **Quick Share с Android** (своя реализация протокола) — отправка и приём файлов, текстов и ссылок: согласие с PIN прямо в карточке, тексты и ссылки с телефона попадают в буфер обмена, режим «Свои устройства» принимает автоматически по сертификатам официального приложения Quick Share для Windows (сертификаты обновляются раз в сутки; пока официальное приложение работает, приём в SideBar приостановлен);
- **окно настроек** (пункт меню значка в трее);
- **русский и английский интерфейс**: «Авто» следует языку Windows, смена языка применяется после перезапуска;
- **проверка обновлений** (см. ниже).

Только Windows 11. Версия 0.1.0; план и история работ — [`docs/PLAN.md`](docs/PLAN.md) и [`HANDOFF.md`](HANDOFF.md).

Неофициальный проект, не связан с Google. «Quick Share» — товарный знак Google LLC.

## Сборка

Требования:

- .NET SDK 10.0.402 (версия закреплена в `global.json`);
- Visual Studio Build Tools с компонентом «Разработка классических приложений на C++» — нужен для NativeAOT.

Тесты (собранный exe запускается напрямую: `dotnet test` с xunit.v3 на .NET 10 даёт «Handshake failures»):

```
dotnet build tests/SideBar.Core.Tests -c Release
tests/SideBar.Core.Tests/bin/Release/net10.0-windows10.0.26100.0/SideBar.Core.Tests.exe
```

Публикация (NativeAOT, результат — `artifacts/app`). Из git-bash перед публикацией добавьте в `PATH` каталог с `vswhere`:
`export PATH="/c/Program Files (x86)/Microsoft Visual Studio/Installer:$PATH"`.

```
dotnet publish src/SideBar.App -c Release -p:Platform=x64 -o artifacts/app
```

## Установка

Скачайте `SideBar-<версия>-setup.exe` из [Releases](https://github.com/Denmurzik/SideBar/releases) (или из артефакта `SideBar-setup` в CI) и запустите. Нужны права администратора: программа ставится в `Program Files\SideBar`.

Перед обновлением закройте SideBar через значок в трее.

Установщик добавляет правило брандмауэра **«SideBar Quick Share»**: входящие подключения по TCP, только в **частных** и **доменных** сетях, только для `SideBar.exe`. Оно нужно для приёма файлов с телефона. Перед добавлением установщик удаляет все входящие правила для этого `SideBar.exe`, в том числе запрещающие: Windows создаёт их, если в запросе брандмауэра нажать «Отмена». При повторной установке правило пересоздаётся, дубликатов нет.

Режим «Свои устройства» требует установленного и авторизованного официального Quick Share для Windows.

Сборка установщика: [`installer/README.md`](installer/README.md).

## Проверка обновлений

Раз в сутки SideBar делает анонимный запрос к `api.github.com` с заголовком `User-Agent: SideBar/<версия>`. Никакие данные не отправляются; в трее появляется пункт, если вышла новая версия. Проверку можно выключить в окне настроек. Пока репозиторий закрыт, проверка сообщает «нет доступных релизов».

Релиз-кандидаты публикуются только как GitHub pre-release: проверка обновлений их не видит.

## Удаление

«Параметры → Приложения → Установленные приложения → SideBar → Удалить». Деинсталлятор удаляет программу, правило брандмауэра и запись автозапуска. Если установщик поднят с правами другой учётной записи администратора, значение автозапуска исходного пользователя не удаляется.

Настройки и данные полки сохраняются: папка `%LOCALAPPDATA%\SideBar` и раздел реестра `HKCU\Software\SideBar`. Чтобы убрать их совсем, удалите папку и раздел вручную. Журнал лежит в `%TEMP%\SideBar\sidebar.log`.

## Структура

- `src/SideBar.Core` — библиотека с логикой без UI;
- `src/SideBar.App` — приложение WinUI 3 (unpackaged, NativeAOT);
- `tests/` — тесты (`SideBar.Core.Tests`);
- `spikes/` — исследовательский код, не часть продукта.
